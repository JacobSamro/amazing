# LAYOUT-40: containment document overflow

Fixed base is LAYOUT-39 `12cf44b4`. The public `layout_overflow_bottom` seam is consumed by document scroll sizing in the shell and headless driver. Applicable containment boundaries now preserve their own border/margin footprint while keeping descendant ink and local scrollable overflow inside the boundary. Previously a fixed-height layout-contained box's overflowing child extended document scroll height. CSS size/style containment alone still allows visible descendant overflow to propagate.

[CSS Containment 2 layout effects](https://www.w3.org/TR/css-contain-2/#containment-layout) classifies visible/clip overflow as ink overflow; scrollable overflow remains local to the box's scroll container. [Paint containment](https://www.w3.org/TR/css-contain-2/#containment-paint) clips descendant overflow. The shared applicability predicate from LAYOUT-39 is reused. This changes document geometry; clipping pixels and stacking semantics remain the separately routed owning-lane follow-up. Generic non-contained overflow behavior is unchanged. No upstream code was copied.

Two grouped actual DOM geometry regressions cover layout/paint/content/strict/size-layout containment across visible/clip/hidden/auto/scroll and static/absolute/fixed descendants (75 variants), plus none/size/inline-size/style/size-style controls. These exercise the installed document overflow seam.
