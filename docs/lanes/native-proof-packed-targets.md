This is a separate source-only capacity ticket, not qualification or permission
for another unchanged CSS attempt. Original CSS link-admission and capacity

`--pack-target label` applies only to explicitly declared `--target` inputs.
Every regular target file and directory is inventoried, with exact bytes/hash,
mode and original physical identity. Actual native/ELF targets stay independently
readable ordinary payloads; no packed measured ELF or remote reference is
admitted. Link metadata remains exact and its complete declared target bytes
are copied losslessly into captured `/srv/amazing-proof` gzip/tar payloads.
The gzip archive never stores an escaping physical link. Raw, source packet,
source tree and measured/generated provenance continue ordinary independent
copy/readback and remain originals at their existing paths.

Initial admission reserves ordinary bytes plus conservative per-member metadata
allocation. Compression writes enforce the same explicit total-copy budget and
actual filesystem reserve before every output chunk. Capacity failure preserves
partial output and rejects completion. The final physical compressed byte count
is measured, not estimated from logical input size; this changes representation,
not the budget or free-space reserve. Every decompressed member byte/hash/mode
and every directory is reverified before completion and each stop admission.
Inventory is repeated against unchanged originals and terminal receipt.

`restore-target` validates the immutable complete archive and actual archival
exit first, then restores into a fresh canonical native namespace using a full
uncompressed-size capacity guard. It hashes every actual restored file, fsyncs
files/directories, preserves original file modes, and retains exact source-link
metadata separately. It never silently creates external/escaping symlinks or
claims a remote reference is restored bytes. Original and captured proof roots
cannot be used as restoration targets.

Native qualification plan: original 108 archive/stop/public/storage/remote
controls plus eight new whole compression controls, in one supported bulk run.
New controls include genuine 64MiB compressed input/full native restore, exact
Unicode and empty/nested paths, ordinary raw/ELF retention, compressed partial
capacity rejection, actual mutation/corruption, malformed/omitted/duplicate/link
members, rejected packed ELF, unchanged legacy behavior and failed-producer
exit preservation. No Mac tests or lifecycle actions. A native source freeze,
packet and finite existing-box grant are required before allocation/execution.
