# Original navigation source CSP reporting loan

Separate successor to the whole received-navigation producer. Source-only: no
native qualification or installed SPVE/Window-retirement proof exists yet.

At genuine live source admission, the caller supplies its actual registered
ReportingDocument, saved ReceivingDocumentClient, original protected Document
status/referrer/source-element metadata and the original owned Manual ApiRequest.
`prepare_navigation_csp_reporting` captures those scalar settings and endpoints
into nonClone/nonDefault NavigationCspSourceLoan and privately binds the request.
The original source remains distinct from the embedding owner and target head.
No Window roots, fresh global registration or public token constructor exists.

The same original request goes through ordinary received-navigation admission.
Authentic Manual continuation preserves its reporting binding while each hop
has its own native admission identity. Captured/previously admitted clones
cannot mint another loan or admit the same loan hop twice. Ordinary callers
without a loan retain existing request reuse and StaleDocument behavior.

`prepare_navigation_csp_report(&mut loan, &actual_receipt, index, queued_at)`
validates the service/private binding and canonical saved policy before preparing
an existing move-only PreparedCspReportPlan. Read-only `violation()` and
`report_snapshot()` expose original SPVE/observer data independently of endpoints.
The actual consumer dispatches SPVE against the original saved Window, then
consumes the plan with queue_prepared_csp_report even on listener errors. This
producer does not manufacture event dispatch or restore a retired Window.
Duplicate native receipts are rejected across retained Manual hop prefixes;
terminal abort/deadline/framing/error receipts retain their actual checked state.

The settings snapshot, receiver and consumed-receipt custody share the existing
bounded prepared content allocation. Report serialization and transport queue
budgets still apply independently. release_navigation_csp_reporting consumes the
loan at actual terminal task cleanup; dropping any capability releases its own
credits. Application content accounting makes no provider/allocator total claim.

Ten native groups use actual source HTTP accepted headers, owned target socket
requests and modern reports+json POST/ReportFinished controls. They cover buffered
and streamed truncation and zero-credit successful heads, admission/abort/deadline/early policy errors, original
retirement, no endpoint snapshots, Manual redirect prefix de-duplication, quota
release, stale/foreign/unrelated bindings and plans, post-admission captures,
policy mismatch and fresh about globals retaining empty endpoint configuration.
The modeled listener error is explicitly native-only. Full original workspace,
doctests, TLS test-support/net/fetch corpus and original11 CSP selection will run
before/after once the repaired prerequisite qualifies and this whole plan freezes.
