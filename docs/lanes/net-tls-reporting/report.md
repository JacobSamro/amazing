# Native CSP Reporting transport source

Recorded published base: a035b2b558065d72664ce7617da0a7261027bb0d. Source only: no build, test, remote job, installed-browser or ready claim. The earlier aaa8d583 TLS/output closure and certificate51ac packet remain unchanged on separate branches. Public source-sync transport qualification is still required before allocation.

NetworkService registers current Reporting-Endpoints from an actual accepted unfiltered response head into a service-local opaque document capability. The driver must bind that capability to the genuine Window/Document/generation. A URL cannot recover it. Authentic about:blank/srcdoc inheritance copies already-resolved endpoints into a distinct child handle; creator retirement does not retire its child. Retirement rejects later admission while already admitted keepalive requests complete. Native policy-container updates may explicitly update future legacy report referrer policy.

The complete RFC9651 parser is ported from ngtcp2/sfparse-rs src/{parser,value,utf8}.rs @00a1a35011e359a466fc05ba1dc39f281b4bafdb, MIT; COPYING SHA256 acdd5bea5a329d2c022ebc2c6858821865355fa834ac1a39f325d08fb577fe70. The crate's unsafe UTF8 conversion is adapted to checked std conversion; no dependency or Cargo change. Original parser controls and embedded Hoehrmann MIT notice remain. Our duplicate/header/string endpoint filtering wraps the complete parser, including ignored values/parameters and all-or-nothing malformed dictionary rejection.

The request machinery uses actual Dispatcher IDs, bounded service aggregate report body retention (64KiB), shared cookies/HSTS/CORS/preflight/redirect checks and an overall 10-second deadline across hops. Current modern endpoints require trustworthy response/target URLs; insecure endpoints and URL credentials are rejected. Reporting sends POST application/reports+json, same-origin credentials, CORS and real preflight. Actual terminal 2xx accepts; 410 removes the matching endpoint; other failures increment its count. Legacy report-uri uses native unsafe application/csp-report, no-cors, same-origin credentials, keepalive and redirect:error without weakening JS Request guards. A present report-to, including invalid/empty/missing endpoint, suppresses legacy fallback. JSON preserves exact UTF16 samples and removes URL credentials/fragments. Report User-Agent uses the same authoritative native constant as HTTP1/HTTP2 encoding.

Prepared controls: 9 new native functions, including 9 actual accepted TCP requests and one refused connection attempt; plus 18 retained upstream parser functions with their original bulk case tables and 11 public parser doctest examples. Native servers read complete headers/body and inspect OPTIONS/POST, Content-Type, actual CSP JSON, origin, cookie presence/absence, Referer, unchanged 307 replay body, 410 removal, CORS-denied preflight stopping POST, legacy redirect rejection, once-only completion, retirement keepalive, zero residual byte credit and atomic rollback. Counts are prepared controls, not passing measurements.

Dependencies for installed proof: HTML's independent22a accepted response metadata producer/carriage, html_resume's native Window/Doc/gen ownership and scheduler route, dom_bindings' separate ReportingObserver algorithm. The runtime must schedule has_pending_reporting_io after ordinary Fetch records disappear and consume real ServiceEvent::ReportFinished. No production runtime or HTML/DOM policy file is edited by this ticket. Installed proofs must use accepted navigation response headers, actual inherited/retired global identity, inline blocked script and event/observer task, and a peer that observes request/body and response completion. Native request tests do not prove browser installation.

Outside this ticket: obsolete Report-To max_age/origin cache; ReportingObserver bindings/task delivery; generic non-CSP report producers; worker installation; retries/backoff; exact provider/kernel buffer totals. No fake registry, URL-derived document identity, synthetic accepted headers, accept-all TLS, logging-only success or zero-status completion marker.

Gate prepared in gate.py: whole workspace nextest --locked --no-fail-fast, whole workspace doctests, whole amazing-net-tls/test-support + amazing-net + amazing-fetch native corpus, before and after on exact commits in one standard linux-run.sh job per phase. Raw logs remain under remote HOME/$OUT; only compact classifications/counts/hashes return. Required zero lost passing classifications. Integrator additionally owns pinned16-shard Test262 and supported installed WPT gate. No measured numbers exist yet.

Primary standards: [Reporting registration/delivery](https://w3c.github.io/reporting/), [CSP reporting](https://www.w3.org/TR/CSP3/#reporting), [RFC9651](https://www.rfc-editor.org/rfc/rfc9651.html). This source implements the document endpoint and CSP request boundary, not all Reporting API surfaces.
