# JS-32: Annex B ordinary-call targets

Source `814beb871b9054f58c4b4b839f0d0dbe91029e97` on fixed JS-31 proof `c8142a1f4e935c372f90606b4203ccfe88da9c30`. An ordinary call in a sloppy assignment/update/iteration target evaluates its callee and arguments, executes the call, and then immediately throws ReferenceError. The returned value is never converted and the RHS never runs; abrupt completion of the call keeps its original identity. Empty iteration never evaluates its target; failed iteration targets retain existing iterator close behavior.

The tree-walking capture_reference Call arm evaluates the call then rejects. VM reference and pattern-reference helpers use existing expression lowering followed by the dedicated RejectCallTarget instruction. Registers/references returned to generic compiler paths are unreachable after rejection; no new Reference value variant, scope, factory, FDI, GDI or scheduling semantics are introduced. Existing expression lowering preserves suspending callee/argument behavior.

Plain grouped calls are recognized through the shared simple-target validator. Strict calls, logical assignment call targets and optional-chain targets remain early syntax errors. Grouping that ends an optional callee chain remains meaningful, and optional expressions in arguments do not invalidate an ordinary call target.

Eight grouped tests exercise both backends: all arithmetic/bitwise assignment operators with argument/call/RHS/conversion ordering, prefix/postfix updates, loop heads and iterator close, thrown identity, strict/logical/optional negatives, grouping/optional arguments, generator interruption and awaited arguments. Tests were written independently, with no upstream source copied. Algorithm reference: [pinned Test262 Annex B call assignment specification](https://raw.githubusercontent.com/tc39/test262/3655e7464de3d52643ecddd4b5f9f4f3e7f62398/test/annexB/language/expressions/assignmenttargettype/callexpression.js). The implementation extends existing MIT-attributed reference infrastructure with an architecture-specific immediate rejection opcode; no fresh port is included.
