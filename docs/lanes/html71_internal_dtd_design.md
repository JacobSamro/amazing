# Internal DTD processing

This ticket adds complete nonvalidating internal-subset processing to the XML parser: general and parameter entity declarations, ELEMENT content models, ATTLIST types/defaults, NOTATION, declaration precedence, entity replacement contexts, attribute normalization and bounded expansion. The engine remains std-only; this implementation contains no ported code.

The parser owns its DTD environment. First definitions win; direct declarations are tracked separately for standalone Entity Declared checks. Internal parameter references occur between complete declarations, while physical references inside internal declarations are rejected. Numeric percent decoding at declaration time remains distinct from physical parameter references. General entity content preserves namespace context, merges ordinary text across replacement boundaries and retains CDATA nodes. Generated CR characters are not normalized a second time. Defaults are applied before namespace resolution. Recursion is a well-formedness error; finite resource budgets report Limit separately. Validity-only constraints do not become mandatory well-formedness failures.

The normative reference is [XML 1.0 Fifth Edition](https://www.w3.org/TR/xml/), especially §§2.8, 3.3, 4.1–4.4 and 5.1. Arbitrary external DTD/entity transport remains unavailable. Existing canonical public-ID behavior is preserved.
